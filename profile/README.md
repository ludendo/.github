# 루덴도 Ludendo

**Ludendo**는 라틴어로 '놀면서'라는 뜻입니다. 라틴어 교육 표어 *Ludendo discimus*(우리는 놀면서 배운다)에서 따왔습니다.

초등학교 교사입니다. 수업에 쓸 웹앱과 게임을 AI와 함께 직접 만들고, 교실에서 학생들과 써 보며 고칩니다.

교실은 실전이 아니라 연습하는 곳이라고 생각합니다. 마음껏 시도하고, 실패하고, 다시 해 보는 곳으로 만들고 싶습니다.

## 하는 일

- 게임으로 하는 수업
- AI로 수업 앱 만들기
- 코딩과 AI 교육
